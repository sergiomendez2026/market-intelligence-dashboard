Metodología

El proyecto sigue un flujo de trabajo de Financial Machine Learning orientado a investigación, diseñado para comparar modelos basados solo en indicadores técnicos contra modelos enriquecidos con sentimiento financiero.

Datos de mercado e indicadores

Precios históricos, medias móviles, RSI, Bandas de Bollinger, volatilidad, retornos y variables de momentum.

Machine Learning

Modelos de regresión y clasificación direccional comparados contra baselines académicos.

Sentimiento con FinBERT

Las noticias financieras se clasifican como positivas, negativas o neutrales y se transforman en variables cuantitativas.

Validación walk-forward

Validación temporal mediante ventanas móviles para reducir sobreajuste y simular una evaluación más realista.

Pruebas estadísticas

Diebold-Mariano, McNemar y bootstrap permiten evaluar diferencias entre modelos.

Explainable AI

La importancia de variables ayuda a interpretar qué factores influyen en el modelo direccional.

Pregunta de investigación

¿El sentimiento financiero extraído con FinBERT mejora la predicción direccional de retornos de corto plazo frente a modelos basados solo en indicadores técnicos?

El dashboard evalúa esta hipótesis mediante un pipeline completo que integra datos de mercado, variables técnicas, variables de sentimiento, baselines académicos, validación walk-forward, pruebas estadísticas e interpretabilidad del modelo.
