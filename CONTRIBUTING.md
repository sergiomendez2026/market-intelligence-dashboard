# Contributing

Gracias por tu interés en contribuir a este proyecto.

Market Intelligence Dashboard es un proyecto académico/profesional orientado a ciencia de datos, machine learning financiero, validación temporal y visualización ejecutiva.

---

## 1. Objetivo de las contribuciones

Las contribuciones deben ayudar a mejorar:

- Calidad del código.
- Cobertura de pruebas.
- Validación de modelos.
- Visualización de resultados.
- Documentación técnica.
- Robustez metodológica.
- Modularidad del sistema.
