Methodology

The project follows a research-oriented financial machine learning workflow designed to compare technical-only models against sentiment-enhanced models.

Market Data & Indicators

Historical prices, moving averages, RSI, Bollinger Bands, volatility, returns and momentum features.

Machine Learning

Regression and directional classification models compared against academic baselines.

FinBERT Sentiment

Financial news are classified as positive, negative or neutral and transformed into quantitative features.

Walk-Forward Validation

Temporal validation using rolling windows to reduce overfitting and simulate realistic evaluation.

Statistical Testing

Diebold-Mariano, McNemar and bootstrap tests are used to evaluate model differences.

Explainable AI

Feature importance helps interpret which variables influence the directional model.

Research Question

Does financial sentiment extracted with FinBERT improve short-term directional forecasting compared with technical-indicator-only models?

The dashboard evaluates this hypothesis through a full pipeline that includes market data, technical features, sentiment variables, academic baselines, walk-forward validation, statistical testing and model interpretability.
